    빠른 시작¶

    5분 만에 Jev를 실행해 봅니다.

    이 가이드는 TypeSafe의 System One 모델인 Jev를 사용하는 네 가지 방법을 다룹니다. SDK 사용하기, API 호출하기, agent skill 사용하기, 브라우저 기반 Playground 써 보기입니다.

    API 키는 TypeSafe 콘솔에서 발급받으세요.

    Jev를 효과적으로 쓰기 위해 알아야 할 최소한의 내용¶

    Jev를 호출할 때마다 요청 하나를 보냅니다. 요청은 state(상태)(단순한 문자열 또는 구조화된 객체이며, 어느 쪽이든 이미지를 포함할 수 있습니다)와 질문 집합으로 이루어지고, 질문마다 답 하나가 반환됩니다.

    %%{init: {"fontFamily": "Inter, sans-serif", "flowchart": {"rankSpacing": 35, "wrappingWidth": 300, "subGraphTitleMargin": {"top": 12, "bottom": 12}}}}%%
flowchart LR
    doc["state<br/><i>평가할 입력 텍스트,<br/>객체 또는 이미지</i>"]
    quest["질문<br/><i>state에 대해<br/>알고 싶은 것</i>"]

    subgraph call["Jev 호출 한 번"]
        direction LR
        doc --> api["TypeSafeClient<br/>.system_one()"]
        quest --> api
    end

    api --> ans["답<br/><i>질문마다 결과 하나</i>"]

    Jev는 primitive(프리미티브: 기본 구성 요소)라고 부르는 다음 질문 유형에 답합니다.

    질문 유형 목적 반환값
    Choice 목록에서 선택지 하나를 고릅니다 choice, probabilities, confidence
    Score rubric(루브릭: 채점 기준)에 따라 state에 점수를 매깁니다 score, probabilities, confidence
    Noul 이 진술이 참인가요? noul (0–1)
    Box 이미지의 어디에 있나요? box (top, bottom, left, right), confidence

    코드로 만들기: 첫 요청¶

    즐겨 쓰는 프로그래밍 언어에서 Jev를 호출하는 방법을 살펴봅니다. Python, JavaScript, TypeScript 예제는 TypeSafe SDK를 사용하고, Bash 예제는 API를 직접 호출합니다.

    작업 디렉토리를 만들고 API 키를 설정하세요. 다음 설정 명령은 macOS, Linux, 또는 WSL을 쓰는 Windows의 Bash 기준입니다.

    mkdir typesafe-quickstart
cd typesafe-quickstart
export TYPESAFE_API_KEY="your-api-key"

    예제는 고객 지원 티켓 하나를 보내고 한 요청으로 Jev에게 세 가지를 묻습니다. 어느 팀이 처리해야 하는지, 고객이 얼마나 불만스러워 보이는지, 문제가 긴급한지입니다.

    route_ticket.py로 저장합니다.

    ```python wrap theme={null} from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

    ticket = "Our API integration started returning 500 errors on every request about 20 minutes ago, and we can't process any customer orders until this is fixed."

    with TypeSafeClient(model="jev-latest") as client: # TYPESAFE_API_KEY를 읽습니다. response = client.system_one( state=ticket, questions={ "department": Choice( instructions="Which team should handle this", criteria={ "billing": "Payment or subscription issues", "technical": "Bugs or integration problems", "sales": "Pricing or account questions", }, ), "frustration": Score( instructions="How frustrated the customer appears", criteria=[ "Calm, just stating facts", "Frustrated but civil", "Very angry, strong language", ], ), "is_urgent": Noul( instructions="The message conveys urgency or time-sensitivity", ), }, )

    print(response.choices["department"].choice) print(response.scores["frustration"].score) print(response.nouls["is_urgent"].noul)

    Node.js 20 이상이 필요합니다. SDK를 설치하고 프로젝트를 ES 모듈로 지정합니다.

    ```bash wrap theme={null} npm install @typesafe-ai/sdk npm pkg set type=module 

    `route_ticket.js`로 저장합니다.

```javascript wrap theme={null}
import { choice, noul, score, TypeSafeClient } from "@typesafe-ai/sdk";

const ticket = "Our API integration started returning 500 errors on every request about 20 minutes ago, and we can't process any customer orders until this is fixed.";

const client = new TypeSafeClient({ defaultModel: "jev-latest" }); // TYPESAFE_API_KEY를 읽습니다.
const response = await client.systemOne({
  state: ticket,
  questions: {
    department: choice("Which team should handle this", {
      billing: "Payment or subscription issues",
      technical: "Bugs or integration problems",
      sales: "Pricing or account questions",
    }),
    frustration: score("How frustrated the customer appears", [
      "Calm, just stating facts",
      "Frustrated but civil",
      "Very angry, strong language",
    ]),
    is_urgent: noul("The message conveys urgency or time-sensitivity"),
  },
});

console.log(response.answers.department.choice);
console.log(response.answers.frustration.score);
console.log(response.answers.is_urgent.noul);

    실행합니다.

    ```bash wrap theme={null} node route_ticket.js

    curl --fail-with-body --silent --show-error \ https://api.typesafe.ai/v1/systemone \ -H "Authorization: Bearer $TYPESAFE_API_KEY" \ -H "Content-Type: application/json" \ --data-binary @- <<'JSON' { "state": "Our API integration started returning 500 errors on every request about 20 minutes ago, and we can't process any customer orders until this is fixed.", "model": "jev-latest", "questions": { "department": { "type": "choice", "instructions": "Which team should handle this", "criteria": { "billing": "Payment or subscription issues", "technical": "Bugs or integration problems", "sales": "Pricing or account questions" } }, "frustration": { "type": "score", "instructions": "How frustrated the customer appears", "criteria": [ "Calm, just stating facts", "Frustrated but civil", "Very angry, strong language" ] }, "is_urgent": { "type": "noul", "instructions": "The message conveys urgency or time-sensitivity" } } } JSON 

    실행합니다.

```bash wrap theme={null}
bash route_ticket.sh

    Jev는 각 질문을 같은 state에 비추어 평가하고, 직접 지정한 ID 아래에 답을 반환합니다. choice는 팀 레이블이고, score는 세 단계로 된 불만 정도 rubric 위의 위치(0–2)이며, noul은 긴급할 확률(0–1)입니다.

    Python, JavaScript, TypeScript 예제는 이 세 값을 출력합니다.

    Example output
    technical
0.67
0.99

    Bash 예제는 가공하지 않은 JSON 응답을 한 줄로 출력합니다. 다음 섹션의 Raw Response에서 각 답의 confidence(신뢰도)와 확률까지 포함해 보기 좋게 정리된 형태를 볼 수 있습니다. 이 값들은 예시 결과이며, Jev 릴리스에 따라 달라질 수 있습니다.

    클라이언트 SDK 페이지에서는 Python 및 JavaScript SDK 설치, 타입이 지정된 답, retry(재시도) 정책을 다룹니다.

    호출하기: API¶

    앞 섹션의 코드 예제 네 개는 모두 이 엔드포인트를 사용합니다. 위의 Bash 탭은 SDK 없이 보내는 완전한 HTTP 요청을 보여 줍니다.

    POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer <API_KEY>
Content-Type: application/json

    [accordion] Raw Response(원본 응답)

    json theme={null} { "model": "jev-1.13.0", "answers": { "department": { "type": "choice", "choice": "technical", "confidence": 1.0, "probabilities": { "technical": 1.0, "billing": 0.0, "sales": 0.0 } }, "frustration": { "type": "score", "score": 0.67, "confidence": 0.5, "legend": { "0": "Calm, just stating facts", "1": "Frustrated but civil", "2": "Very angry, strong language" }, "probabilities": { "0": 0.33, "1": 0.67, "2": 0.0 } }, "is_urgent": { "type": "noul", "noul": 0.99 } }, "usage": { "input_tokens": 428, "output_tokens": 73 } }

    API 레퍼런스에는 모든 요청 필드, 질문 유형, 답 유형이 정리되어 있습니다.

    써 보기: Playground¶

    Playground는 브라우저에서 Jev를 실행합니다. 코드를 작성하지 않고도 state를 붙여 넣고, 질문을 추가하고, 답을 읽을 수 있습니다.

    1. Playground를 열고 로그인합니다.
    2. 아무 텍스트나 붙여 넣어 state로 사용합니다.
    Sample state
    Our API integration started returning 500 errors on every request about 20 minutes ago, and we can't process any customer orders until this is fixed.
    1. 질문을 추가합니다. Noul 질문을 써 보세요: "Does this message express urgency?"
    {
  "urgency": {
    "type": "noul",
    "instructions": "Does this message express urgency?"
  }
}
    1. 질문을 더 추가합니다. 한 요청에 Noul, Choice, Score 질문을 섞어 넣고 모든 결과를 한꺼번에 확인하세요.

    다음 단계¶

    LLM에 익숙하더라도 primitive를 조합해 더 큰 시스템을 만드는 데는 어느 정도 연습이 필요합니다. 머신 러닝 입문은 Jev가 왜 생성된 텍스트 대신 calibrated(보정된) 확률을 반환하는지, 그리고 그에 따라 구축 방식이 어떻게 달라지는지 설명합니다.

    Primitive와 사용 사례 맵도 살펴보시기를 권합니다.

    1. 오류와 retry
    2. 병렬 질문

    이 문서는 개발자 문서 플랫폼인 Mintlify로 제작하고 호스팅합니다.
