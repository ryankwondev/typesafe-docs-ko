    System One¶

    state에 담아 보낸 콘텐츠에 대해 하나 이상의 질문에 답합니다.

    한 요청 안에 여러 질문 유형을 섞어 쓸 수 있습니다. 답은 질문과 같은 이름을 사용하므로 각 결과를 해당 질문과 짝지을 수 있습니다. 응답에는 사용된 모델과 token(토큰) 사용량도 함께 들어 있습니다.
