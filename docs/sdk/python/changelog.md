# 변경 이력

> TypeSafe AI API를 위한 Python 클라이언트

## v0.7.5 (2026-10-14)

### 문서

* 사용 가이드를 Basic과 Advanced 페이지로 나눴습니다.
* 이미지를 다루는 방법에 관한 문서를 추가했습니다.
* `Box` 타입 문서를 추가했습니다.

### 기능

* `zstd`를 이용한 요청 본문 압축을 기본으로 켭니다(비공식 API는 이를 바로 지원하지 않을 수 있습니다).
* 원시 바이트, 파일 경로, base64 문자열, PIL 객체로 만든 `Image` asset(첨부 자산)을 지원합니다.
* `Box` 질문과 답변을 지원합니다.
* `attach_assets`로 텍스트 안에서 asset을 참조할 수 있습니다.

## v0.7.4 (2026-10-09)

### 버그 수정

* 유한하지 않은 숫자를 유효하지 않은 JSON token(토큰) 대신 문자열로 직렬화합니다.

## v0.7.3 (2026-10-09)

### 버그 수정

* `truststore<=0.10.4`에서 TLS 연결을 동시에 맺을 때 비동기 클라이언트가 크래시하던 문제를 막았습니다.
* 요청 유효성 검사 항목을 더 추가했습니다.

### 문서

* 동시성이 높은 환경에서 쓸 수 있는 팁을 담은 Performance 섹션을 새로 추가했습니다.

### 성능

* 풀에 있는 모든 연결을 30초 동안 유지하도록 기본 설정을 바꿨습니다.

## v0.7.2 (2026-09-26)

### 기타

* `typesafe-sdk` 패키지에 `http2` extra(추가 설치 옵션)를 추가했습니다.

### 문서

* HTTP/2 지원과 함께 `typesafe-sdk`를 사용하는 방법을 문서에 실었습니다.

## v0.7.1 (2026-09-21)

### 버그 수정

* API 키를 초기에 검증하고, 로그에 남는 예외에서 키 값을 제외합니다.

### 문서

* AI 게이트웨이와 함께 사용하는 예제를 추가했습니다.

## v0.7.0 (2026-09-18)

### 호환성이 깨지는 변경

* 직렬화/역직렬화 라이브러리를 `msgspec`에서 `pydantic`으로 바꿨습니다.

### 버그 수정

* `str`의 서브클래스를 문자 리스트가 아니라 문자열로 올바르게 직렬화합니다.

### 기능

* `system_one` 메서드가 새 인자 `response_model`을 받습니다. 원하는 `pydantic` 모델을 지정하면 *type-safety(타입 안전성)*를 더 높일 수 있습니다.

## v0.6.0 (2026-09-15)

### 호환성이 깨지는 변경

* `Score.criteria`를 정수 키 딕셔너리 대신 순서가 있는 시퀀스로 받습니다.

### 기능

* SDK 입력의 타입 어노테이션을 개선해 `Mapping`, `Sequence` 같은 추상 타입을 받을 수 있습니다.
* 오류 메시지에 http 세부 정보와 메타데이터가 포함되도록 개선했습니다.

### 버그 수정

* `RetryPolicy`의 유효하지 않은 값을 처리합니다.
* 예외와 응답을 pickle할 수 있게 했습니다.

### 문서

* 메인 [문서](../../index.md)의 개념으로 가는 링크를 더 추가했습니다.

## v0.5.7 (2026-09-14)

TypeSafe Python SDK의 첫 공개 릴리스입니다. 자세한 내용은 [문서](https://docs.typesafe.ai/go/python-sdk.md)에서 확인하세요.


이 문서는 개발자 문서 플랫폼인 [Mintlify](https://mintlify.com)로 제작하고 호스팅합니다.
