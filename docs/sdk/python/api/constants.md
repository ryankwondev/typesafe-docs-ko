# 상수

> TypeSafe Python SDK의 기본 설정과 환경 변수 이름입니다.

## typesafe\_sdk.constants

공개 환경 변수 이름과 클라이언트 기본값입니다.

### API\_KEY\_ENV

`module-attribute`

```python
API_KEY_ENV = 'TYPESAFE_API_KEY'
```

API 키를 지정하는 환경 변수입니다.

### BASE\_URL\_ENV

`module-attribute`

```python
BASE_URL_ENV = 'TYPESAFE_BASE_URL'
```

API base URL을 지정하는 환경 변수입니다.

### DEFAULT\_MODEL\_ENV

`module-attribute`

```python
DEFAULT_MODEL_ENV = 'TYPESAFE_DEFAULT_MODEL'
```

기본 모델을 지정하는 환경 변수입니다.

### LOG\_LEVEL\_ENV

`module-attribute`

```python
LOG_LEVEL_ENV = 'TYPESAFE_LOG_LEVEL'
```

로깅 수준을 지정하는 환경 변수입니다.

### DEFAULT\_BASE\_URL

`module-attribute`

```python
DEFAULT_BASE_URL = 'https://api.typesafe.ai'
```

기본 API base URL입니다.

### DEFAULT\_MODEL

`module-attribute`

```python
DEFAULT_MODEL = 'jev-latest'
```

기본 모델 이름입니다.

### DEFAULT\_TIMEOUT

`module-attribute`

```python
DEFAULT_TIMEOUT = 10.0
```

HTTP 작업 하나에 적용되는 기본 타임아웃(초)입니다.


이 문서는 개발자 문서 플랫폼인 [Mintlify](https://mintlify.com)로 제작하고 호스팅합니다.
