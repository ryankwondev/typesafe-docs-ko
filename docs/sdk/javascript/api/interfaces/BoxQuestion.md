# Interface: BoxQuestion

instructions(지시문)가 설명하는 대상을 요청의 이미지에서 찾는 질문입니다.

## Properties

### instructions?

```ts
optional instructions?: EntryType;
```

찾을 대상입니다. 텍스트, asset(첨부 자산), JSON 객체, 배열 중 하나로 지정하며, 생략하거나 `null`로 둘 수 있습니다.

***

### type

```ts
type: "box";
```
