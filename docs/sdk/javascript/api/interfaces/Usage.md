# Interface: Usage

요청 하나의 token(토큰) 사용량입니다.

## Properties

### input\_tokens

```ts
readonly input_tokens: number | null;
```

사용한 입력 token 수입니다. API가 값을 알려 주지 않으면 `null`입니다.

***

### output\_tokens

```ts
readonly output_tokens: number | null;
```

사용한 출력 token 수입니다. API가 값을 알려 주지 않으면 `null`입니다.


이 문서는 개발자 문서 플랫폼인 [Mintlify](https://mintlify.com)로 제작하고 호스팅합니다.
