# 클라이언트 SDK

> TypeSafe 클라이언트 SDK를 설치하고 애플리케이션에서 타입이 지정된 질문과 답을 사용하세요.

TypeSafe 클라이언트 SDK는 TypeSafe API에 쓸 타입이 지정된 질문과 답을 제공하며, 기본 retry(재시도) 정책에 따라 retry를 자동으로 처리합니다.

설치 방법, 예제, API 세부 사항을 보려면 클라이언트 SDK를 선택하세요.

> [card] [Python](sdk/python.md)
>
> Python 클라이언트 SDK를 설치하고 첫 요청을 보내 봅니다.

> [card] [JavaScript / TypeScript](sdk/javascript.md)
>
> JavaScript 클라이언트 SDK를 설치하고 타입이 지정된 첫 요청을 보내 봅니다.

어떤 언어에서든 [HTTP API](https://docs.typesafe.ai/api)를 직접 호출할 수도 있습니다.


이 문서는 개발자 문서 플랫폼인 [Mintlify](https://mintlify.com)로 제작하고 호스팅합니다.
