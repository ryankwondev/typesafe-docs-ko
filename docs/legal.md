# 법적 고지

> TypeSafe의 법률 문서와 정책입니다.

아래 문서들은 TypeSafe 계정을 보유한 고객의 데이터를 TypeSafe가 어떻게 다루는지 설명합니다. 데이터 보존, 사용자 데이터로 모델을 학습시키지 않겠다는 약속, 그리고 TypeSafe 이용 전반에 적용되는 일반 고객 계약이 포함됩니다.

## 법률 문서

* [데이터 처리 계약(Data Processing Agreement)](https://typesafe.ai/legal/data-processing): 데이터 보존을 포함해, TypeSafe가 고객을 대신해 고객 데이터를 처리하는 방식을 다룹니다.
* [기본 고객 계약(Master Customer Agreement)](https://typesafe.ai/legal/mca): TypeSafe 계정에 적용되는 일반 약관입니다.
* [개인정보 처리방침(Privacy Policy)](https://typesafe.ai/legal/privacy-policy): 어떤 데이터를 수집하고 어떻게 사용하는지 설명하며, 사용자 데이터로 모델을 학습시키지 않겠다는 약속도 담고 있습니다.

엔터프라이즈 고객에게는 zero data retention(ZDR, 데이터 무보존)도 제공합니다. 자세한 내용은 [지원 요청 양식](https://support.typesafe.ai/forms/support-request)을 작성해 문의하세요.


이 문서는 개발자 문서 플랫폼인 [Mintlify](https://mintlify.com)로 제작하고 호스팅합니다.
