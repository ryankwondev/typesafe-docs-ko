    동기 클라이언트¶

    TypeSafeClient로 질문을 보내고, 모델 목록을 조회하고, 동기 방식의 TypeSafe API 요청을 설정합니다.

    typesafe_sdk.TypeSafeClient¶

    시그니처 복사

    `TypeSafeClient(
    \*,
    api\_key: [str](https://docs.python.org/3/builtins/stdtypes.html#str) | None = None,
    model: [str](https://docs.python.org/3/builtins/stdtypes.html#str) | None = None,
    retry: [RetryPolicy](../retries.md#typesafe_sdk.RetryPolicy) | None = None,
    timeout: [float](https://docs.python.org/3/builtins/functions.html#float)
    | httpx2.Timeout
    | None = None,
    headers: [Mapping](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[str](https://docs.python.org/3/builtins/stdtypes.html#str), [str](https://docs.python.org/3/builtins/stdtypes.html#str)] | None = None,
    transport: httpx2.BaseTransport
    | None = None,
    http\_client: httpx2.[Client](https://pydantic.dev/docs/httpx2/api/api/#httpx2.Client) | None = None,
    base\_url: [str](https://docs.python.org/3/builtins/stdtypes.html#str) | None = None,
    compression: [Literal](https://docs.python.org/3/library/typing.html#typing.Literal)\["zstd", False]
    | None = None,
)`

    TypeSafe AI API용 HTTP 클라이언트를 생성합니다.

    명시적으로 전달한 옵션이 환경 변수보다 우선합니다. 환경 변수 값이 비어 있거나 공백뿐이면 무시합니다.

    [!TIP]

    로깅 설정

    SDK는 typesafe_sdk 로거에 로그를 남깁니다. 표준 logging으로 설정하거나, 간단히 기본값만 정하려면 TYPESAFE_LOG_LEVEL(debug, info, ...)을 설정하세요. 비밀 값이 담긴 헤더는 로그 출력에서 가려지지만, 요청과 응답 본문은 가려지지 않습니다.

    Parameters(매개변수):

    • api_key (str | None, default: None ) –

    필수 API 키입니다. 환경 변수 TYPESAFE_API_KEY로도 설정할 수 있습니다. 앞뒤 공백은 제거됩니다. 빈 키, 중간에 공백이 있는 키, 제어 문자나 ASCII가 아닌 문자가 들어 있는 키는 거부됩니다. * model (str | None, default: None ) –

    모델 이름입니다. 환경 변수 TYPESAFE_DEFAULT_MODEL로도 설정할 수 있습니다. * retry (RetryPolicy | None, default: None ) –

    retry(재시도) 동작을 제어하는 RetryPolicy입니다. 쓸 수 있는 옵션과 기본값은 RetryPolicy를 참고하세요. retry를 끄려면 RetryPolicy(max_retries=0)을 전달합니다. * timeout (float | httpx2.Timeout | None, default: None ) –

    HTTP 작업의 타임아웃입니다. http_client를 전달했다면 http_client.timeout을 물려받고, 그렇지 않으면 SDK 기본값을 씁니다. * headers (Mapping[str, str] | None, default: None ) –

    추가로 설정할 요청 헤더입니다. * transport (httpx2.BaseTransport | None, default: None ) –

    선택적으로 지정하는 사용자 정의 HTTP transport입니다. 이 SDK 클라이언트가 닫힐 때 함께 닫힙니다. * http_client (httpx2.Client | None, default: None ) –

    선택적으로 지정하는 httpx2.Client입니다. transport와 함께 쓸 수 없습니다. 이 SDK 클라이언트가 닫힐 때 함께 닫힙니다. * base_url (str | None, default: None ) –

    API 루트입니다. 환경 변수 TYPESAFE_BASE_URL로도 설정할 수 있습니다. * compression (Literal['zstd', False] | None, default: None ) –

    요청 본문 압축 방식입니다. "zstd"를 지정하거나, 본문을 압축하지 않고 보내려면 False를 지정합니다. 사용할 수 있는 경우 기본값은 zstd입니다.

    Raises(예외):

    • TypeSafeError –

    API 키가 없거나 유효하지 않은 경우, 타임아웃이 유효하지 않은 경우, zstd 압축을 쓸 수 없는 경우에 발생합니다. * ValueError –

    transport와 http_client를 둘 다 전달한 경우에 발생합니다.

    Examples(예제):

    from typesafe_sdk import Choice, Noul, TypeSafeClient

with TypeSafeClient() as client:
    result = client.system_one(
        state="I was charged twice. Please help.",
        questions={
            "billing": Noul(instructions="Is this about billing?"),
            "tone": Choice(
                instructions="What is the tone?",
                criteria={"calm": None, "angry": None},
            ),
        },
    )
    assert 0 <= result.nouls["billing"].noul <= 1
    assert result.choices["tone"].choice in {"calm", "angry"}

    attach_assets¶

    시그니처 복사

    `attach\_assets(
    assets: [Asset](../types/assets.md#typesafe_sdk.Asset) | [Sequence](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence)\[[Asset](../types/assets.md#typesafe_sdk.Asset)],
) -> [AbstractContextManager](https://docs.python.org/3/library/contextlib.html#contextlib.AbstractContextManager)\[None]`

    with 블록 안에서 일어나는 호출에 asset(첨부 자산)을 첨부해, 문자열 안에서 asset을 참조할 수 있게 합니다.

    블록을 벗어나기 전까지 이 클라이언트로 보내는 호출은, 첨부된 asset 가운데 그 참조인 str(asset)이 요청에 들어 있는 것을 모두 함께 전송합니다.

    [!WARNING]

    경고

    SDK는 첨부된 asset, assets로 전달한 asset, 내용 안에 직접 넣은 asset의 참조만 인식합니다. 그 밖의 asset을 가리키는 참조는 asset 없이 일반 텍스트로 전송됩니다.

    Parameters:

    • assets (Asset | Sequence[Asset]) –

    asset 하나 또는 asset의 시퀀스입니다.

    Raises:

    • TypeSafeError –

    첨부한 값이 asset이 아닌 경우에 발생합니다.

    Examples:

    from pathlib import Path

from typesafe_sdk import Image, Noul, SystemOneResponse, TypeSafeClient


def inspect(client: TypeSafeClient, path: Path) -> SystemOneResponse:
    photo = Image(path)
    with client.attach_assets(photo):
        return client.system_one(
            state=f"Product: {photo}",
            questions={"damaged": Noul(instructions="Is the product damaged?")},
        )

    Parameters:

    평가할 텍스트, asset, JSON 객체 또는 배열입니다. 자세한 내용은 state를 참고하세요. * questions (Mapping[str, Question]) –
