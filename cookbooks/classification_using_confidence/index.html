    confidence를 활용한 분류¶

    SEC 연차 보고서를 문서당 Choice 하나로 75개 산업 그룹에 분류한 다음, 답변에 딸려 오는 confidence(신뢰도)를 읽어 그 그룹을 보고할지 한 단계 위의 더 넓은 부문을 보고할지 결정합니다.

    SEC에 연차 보고서를 제출하는 회사는 모두 그 보고서 안에 자기 사업을 직접 설명합니다. 여기서는 그 설명을 Standard Industrial Classification(표준 산업 분류, SIC)에 따라 분류합니다. 산업 그룹은 75개이고, 문서 하나에 Choice 질문 하나를 씁니다.

    쉬운 문서가 많습니다. 지방 은행은 지방 은행입니다. 그렇지 않은 문서도 있습니다. 두 사업 부문 중 하나를 막 매각한 회사, 지금 운영하는 사업이 아니라 앞으로 진입할 사업을 설명하는 스타트업이 그렇습니다. 그래도 모델은 그룹 하나를 골라야 하고, 어려운 사례의 답은 쉬운 사례의 답과 겉보기에 다르지 않습니다. 어려운 사례와 쉬운 사례를 가려내는 일에 보통 비용이 들어갑니다. 두 번째 모델, 추가 호출, 사람 검토 같은 것입니다.

    Choice는 이미 그 정보를 알려 줍니다. 선택된 선택지와 함께 confidence를 반환하는데, 확률이 거의 전부 한 선택지에 몰리면 높고 여러 선택지에 퍼지면 낮습니다. 이 숫자 하나로 믿어도 되는 답과 그렇지 않은 답이 나뉩니다.

    믿기 어려운 답을 어떻게 처리할지는 라벨 구조에 달려 있습니다. SIC 라벨은 계층을 이룹니다. 산업 그룹이 모여 더 넓은 부문이 됩니다. 모델이 그룹을 확신하지 못하면 그 그룹이 속한 부문을 보고합니다. 부문은 그룹에서 바로 정해지므로 호출을 한 번 더 할 필요가 없습니다.

    공시 문서 60건에 confidence 기준값 0.9를 적용하면 28건은 확신하는 답, 32건은 그렇지 않은 답으로 나뉩니다. 확신하는 28건은 93%가 맞고, 나머지 32건은 50%가 맞습니다. 이 32건을 한 단계 위로 올려 보고하면 50%가 78%로 올라갑니다.

    taxonomy의 두 단계 만들기¶

    sic_codes.tsv는 SEC가 제출 회사에게 자기 코드를 고르라고 공개하는 산업 목록으로, 2026-08-10에 가져온 것입니다. 네 자리 코드 444개가 있고 코드마다 산업 명칭이 붙어 있습니다. 코드의 숫자가 곧 계층입니다. 앞의 두 자리가 major group(대분류 그룹)이고(여기서는 01 agricultural production부터 99 non-classifiable까지 75개), major group을 정해진 범위로 묶은 것이 열 개의 division(부문)입니다. division은 SIC에서 가장 넓은 구분입니다.

    두 단계 모두 모델 없이 이 파일 하나에서 나옵니다. 코드를 앞의 두 자리로 묶고, 그 두 자리를 division에 대응시키면 됩니다.

    DIVISIONS = [
    (1, 9, "agriculture, forestry and fishing"),
    (10, 14, "mining"),
    (15, 17, "construction"),
    (20, 39, "manufacturing"),
    (40, 49, "transportation, communications and utilities"),
    (50, 51, "wholesale trade"),
    (52, 59, "retail trade"),
    (60, 67, "finance, insurance and real estate"),
    (70, 89, "services"),
    (91, 99, "public administration"),
]

INDUSTRIES: dict[str, str] = {}
for line in download("sic_codes.tsv").read_text().splitlines()[1:]:
    code, _office, title = line.split("\t")
    INDUSTRIES[code] = title.lower()

GROUPS: dict[str, list[str]] = defaultdict(list)
for code in sorted(INDUSTRIES):
    GROUPS[code[:2]].append(code)


def division(group: str) -> str:
    number = int(group)
    return next(name for low, high, name in DIVISIONS if low <= number <= high)


print(
    f"{len(INDUSTRIES)} industries -> {len(GROUPS)} major groups -> {len(DIVISIONS)} divisions"
)
print(
    f"  group 35 = {division('35')} / {', '.join(INDUSTRIES[c] for c in GROUPS['35'][:3])} ..."
)

    444 industries -> 75 major groups -> 10 divisions
  group 35 = manufacturing / engines & turbines, farm machinery & equipment, lawn & garden tractors & home lawn & gardens equip ...

    Choice 질문에는 각 선택지를 설명할 내용이 필요한데, 그룹 자체의 이름이 항상 있는 것은 아닙니다. SEC 목록에서 75개 중 42개에는 그룹 전체를 아우르는 명칭이 있고 나머지에는 없습니다. 그래서 각 그룹을 그 안에 속한 산업들로 설명합니다. 공시 문서를 읽는 사람도 어차피 그 산업들과 맞춰 보게 됩니다.

    MAX_NAMED = (
    8  # 그룹당 나열하는 산업 수. 글이 지나치게 길어지지 않으면서 그룹의 성격을 드러내기에 충분
)


def describe(group: str) -> str:
    umbrella = INDUSTRIES.get(f"{group}00")
    inside = [INDUSTRIES[c] for c in GROUPS[group] if c != f"{group}00"][:MAX_NAMED]
    listed = "; ".join(inside)
    return (
        f"{umbrella} — includes: {listed}"
        if umbrella and listed
        else (umbrella or listed)
    )


print(f"group 20: {describe('20')[:150]}")
print(f"\ngroup 65: {describe('65')[:150]}")

    group 20: food and kindred products — includes: meat packing plants; sausages & other prepared meat products; poultry slaughtering and processing; dairy product

group 65: real estate — includes: real estate operators (no developers) & lessors; operators of nonresidential buildings; operators of apartment buildings; less

    공시 문서¶

    filings.jsonl에는 연차 보고서(10-K) 60건이 들어 있습니다. 각 문서는 Item 1 "Business"만 남기고 잘라 냈습니다. 회사가 무슨 일을 하는지 설명하는 섹션이고, 산업 코드와 관련된 부분은 여기뿐입니다. 문서의 연도는 1993–2024년에 걸쳐 있고 길이는 700단어에서 2,200단어 사이입니다. 문서마다 제출 회사가 고른 SIC 코드와, EDGAR에서 찾아볼 수 있는 accession number(접수 번호)가 함께 들어 있습니다.

    이 라벨은 회사가 스스로 보고한 것입니다. 공시 문서를 작성한 사람이 한 번 고른 값이고, 회사가 코드가 가리키는 사업을 매각하고도 코드를 그대로 두면 낡은 값이 됩니다. 이 60건은 문서 본문이 자기 코드를 뒷받침하는 것만 남도록 걸러 낸 것이므로, 여기 나오는 수치는 EDGAR 메타데이터의 상태가 아니라 이 방법 자체를 측정합니다.

    Choice 질문 하나를 던지고 confidence 읽기¶

    taxonomy(분류 체계) 전체가 요청 하나에 들어갑니다. Choice는 선택지 약 240개까지 안정적으로 동작하고, 75개는 그 범위 안에 넉넉히 들어갑니다.

    답에는 선택된 그룹인 choice, 75개 각각에 실린 가중치인 probabilities, 그리고 그 분포가 얼마나 한곳에 몰렸는지 알려 주는 confidence가 함께 돌아옵니다. 이 방법은 1위 선택지의 확률이 아니라 confidence를 읽습니다. 1위가 0.45이고 2위가 0.44인 경우와, 1위가 0.45이고 나머지 가중치가 얇게 흩어진 경우는 서로 다른 상황이며, 둘을 구분해 주는 값이 confidence입니다.

    QUESTION = (
    "Which broad industry does this company operate in? Judge the company's own operations "
    "as this filing describes them."
)


def questions() -> dict:
    return {
        "group": Choice(
            instructions=QUESTION,
            criteria={group: describe(group) for group in sorted(GROUPS)},
        )
    }


@json_cache
def ask(text: str, group: Choice, model: str) -> dict:
    response = client.system_one(
        state=text, questions={"group": group}, model=model
    )
    answer = response.answers["group"]
    return {
        "group": answer.choice,
        "confidence": answer.confidence,
        "probabilities": dict(answer.probabilities),
    }

    확신하면 그룹을, 아니면 그 그룹의 division을 반환하기¶

    confidence가 0.9 이상이면 답을 산업 그룹으로 보고합니다. 그보다 낮으면 같은 답을 그 그룹이 속한 division으로 보고합니다.

    모든 공시 문서가 쓸 수 있는 라벨을 달고 돌아옵니다. 모델이 확신을 갖고 분류하지 못한 문서는 버려지거나 다른 곳으로 넘겨지는 대신 한 단계 위의 라벨로 돌아옵니다. division이 너무 거칠어서 애플리케이션에서 쓸 수 없다면, 이 분기가 사람에게 넘기는 지점입니다.

    def classify(filing: dict) -> dict:
    answer = ask(filing["text"], questions()["group"], model=TYPESAFE_MODEL)
    sure = answer["confidence"] >= CONFIDENT
    return {
        "level": "group" if sure else "division",
        "label": answer["group"] if sure else division(answer["group"]),
        "confidence": answer["confidence"],
        "group": answer["group"],
    }


def show(filing: dict) -> None:
    result = classify(filing)
    named = describe(result["group"]).split(" — ")[0][:46]
    print(
        f"  {filing['id']:>13}  conf {result['confidence']:.2f}  -> {result['level']:<8} "
        f"{result['label']:<14} (group {result['group']}: {named})"
    )


print("three filings the model was sure about:")
for f in sorted(FILINGS, key=lambda f: -classify(f)["confidence"])[:3]:
    show(f)
print("\nthree it was not:")
for f in sorted(FILINGS, key=lambda f: classify(f)["confidence"])[:3]:
    show(f)

    confidence는 각 문서를 분류하기가 얼마나 어려운지와 맞아떨어집니다. 모두 1.00인 상위 세 건은 마케팅 회사, 제약 회사, 카펫 제조사입니다. 세 회사 모두 예전 사업을 매각했거나 그만두었지만, 문서마다 지금 운영하는 사업 하나를 분명하게 밝히고 있습니다. 하위 세 건이 더 어려운 이유는 본문에서 읽어 낼 수 있습니다. 두 건은 아직 시작하지 않은 사업을 설명하는 스타트업이고(Nevaeh는 "intends to operate as a software developer"라고 쓰고, Hotel Management Systems는 임원이 한 명뿐이며 "planned operations"에 대해 씁니다), 나머지 한 건은 사업 부문이 두 개였다가 제출 몇 주 전에 하나를 매각했습니다. 이 세 건은 그룹이 아니라 division으로 돌아옵니다.

    def correct(filing: dict, result: dict) -> bool:
    gold_group = filing["sic"][:2]
    if result["level"] == "group":
        return result["label"] == gold_group
    return result["label"] == division(gold_group)

def draw_split(p: dict) -> plt.Figure:
    ink = {key: p["ink"] for key in ("text.color", "axes.labelcolor", "axes.edgecolor", "xtick.color", "ytick.color")}
    with matplotlib.rc_context(ink):
        fig, ax = plt.subplots(figsize=(7, 3.6), facecolor=p["surface"])
        ax.set_facecolor(p["surface"])
        x = range(len(labels))
        ax.bar(
            [i - 0.19 for i in x],
            forced_split,
            0.38,
            label="always name a group",
            color=p["forced"],
        )
        ax.bar(
            [i + 0.19 for i in x],
            broad_split,
            0.38,
            label="answer broadly when unsure",
            color=p["broad"],
        )
        for i, (a, b) in enumerate(zip(forced_split, broad_split)):
            ax.text(i - 0.19, a + 0.02, f"{a:.0%}", ha="center", fontsize=9)
            ax.text(i + 0.19, b + 0.02, f"{b:.0%}", ha="center", fontsize=9)
        ax.set_xticks(list(x))
        ax.set_xticklabels(
            [f"{lab}\nn={n}" for lab, n in zip(labels, [len(sure), len(unsure)])]
        )
        ax.set_ylabel("labels that are right")
        ax.set_ylim(0, 1.12)
        ax.set_title("Where the broader answer helps: the filings it was unsure about")
        ax.legend(frameon=False, loc="upper right")
        ax.spines[["top", "right"]].set_visible(False)
        fig.tight_layout()
        return fig
